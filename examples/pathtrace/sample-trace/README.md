# Sample end-to-end network trace of `GET /trace`

Two complementary captures of the same endpoint, taken 2026-07-29. Together they trace the
request from the client all the way to the app and back — client-side wire/timing plus the
server-side per-hop view.

## Files
| File | Vantage | What it shows |
|---|---|---|
| `01-wire-trace.txt` | client (curl `--trace-ascii`) | raw TLS handshake + HTTP/2 request/response bytes |
| `02-response-headers.txt` | client | response headers of the **unauthenticated** leg (302) |
| `03-timing.txt` | client | DNS/TCP/TLS/TTFB timing + the 302 → Entra redirect |
| `04-authenticated-trace.json` | browser (logged-in) | the **authenticated** 200: response headers + timings + full 7-hop server-side evidence |

## The two legs

**Unauthenticated (`01`–`03`)** — proves the whole front half of the path runs even before login:
```
client → Cloudflare edge → tunnel → Istio gateway → ext_authz(oauth2-proxy) → 302 → Entra
HTTP/2 302 · server: cloudflare · cf-ray: a22f57… · set-cookie: _oauth2_proxy_csrf · location: login.microsoftonline.com
DNS 0.00s · TCP 0.027s · TLS 0.066s · TTFB 0.345s
```
The 302 is generated by oauth2-proxy *through* the gateway's ext_authz, so a redirect here
proves edge + tunnel + gateway + auth all executed.

**Authenticated (`04`)** — the full round trip to the app with a valid session:
```
path: client → Cloudflare → 2 proxy hops → Istio/Envoy → oauth2-proxy → Istio mTLS (SPIFFE) → app
HTTP 200 · x-envoy-upstream-service-time: 3ms (gateway→app hop) · content-encoding: zstd
nav timing: DNS 55ms · TCP 43ms · TLS 43ms · TTFB 312ms · total 432ms
```
Every hop resolved to a **specific vendor** (7 vendor-identified / 0 generic / 0 not seen),
each backed by the header that hop physically stamped — including the SSO identity
(`x-auth-request-email`) and the mTLS caller (`spiffe://…/aks-istio-ingressgateway-internal`).

## How to re-capture
```sh
IP=$(dig +short driftscope.justmakeitgo.net @1.1.1.1 | grep -E '^[0-9]' | head -1)
# client-side (unauth leg):
curl -sS --resolve driftscope.justmakeitgo.net:443:$IP \
  --trace-ascii 01-wire-trace.txt -D 02-response-headers.txt -o /dev/null \
  -w 'DNS %{time_namelookup} TCP %{time_connect} TLS %{time_appconnect} TTFB %{time_starttransfer} total %{time_total} -> %{http_code}\n' \
  https://driftscope.justmakeitgo.net/trace
# authenticated end-to-end: open /trace in a browser, sign in, then GET /trace?format=json
```

> Redaction: the public client IP is masked to `47.6.x.x`; internal pod IPs and the SPIFFE
> identities are kept (not sensitive). The email is the repo author's own.
